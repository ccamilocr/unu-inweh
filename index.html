Branching

Feature branches per unit, pull requests before merging to main. Hotfix branches for production patches.

Pipeline

Feature → review → staging → Docker rebuild → tagged release. Rollback via Docker image versioning.

Backup

Automated pg_dump / mongodump cron jobs, Docker volume snapshots, environment configs in private repo with secrets management.

Security

No hardcoded credentials. Production deployments require tagged releases. Access via SSH keys and scoped repo permissions.
